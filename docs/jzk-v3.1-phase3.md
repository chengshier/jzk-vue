# 九州康 JZK V3.1 第三批管理端

本分支叠加在 `feat/jzk-v3.1-phase2-business` 之上。

已接入：

- 库存盘点；
- 异常收货 V2 分项处理；
- 真实微信推广码场景；
- 微信订阅消息任务；
- 健康周报月报。

异常收货 V2 已完成以下可用性收口：

- 旧工作台不再允许直接标记处理完成；
- 统一进入 V2 分项处理方案；
- 从真实异常单加载商品、规格、短缺和破损数据；
- 不要求管理员手填异常商品明细 ID；
- 展示已分配数量和剩余可处理数量；
- 补发、退款、退回或接受方案不会在创建时伪造库存或资金动作。

订阅消息任务管理已补充：

- 区分待发送、发送处理中、等待重试、等待配置、等待接收人授权、发送成功和发送失败；
- 展示待处理、处理中、等待配置、等待授权和失败数量；
- `PROCESSING` 任务不允许人工重复入队；
- 重新入队时由后端刷新用户当前可信小程序 openId；
- 手动处理后按接口真实返回值展示成功发送数量；
- 多实例抢占和超时恢复由后端保障，页面不把排队或处理中显示为成功。

边界：

- 使用 Vue2 + Element UI；
- 微信、MinIO 和模板未配置时显示不可用；
- 不生成占位二维码；
- 不把排队任务显示为发送成功；
- 普通管理员必须由系统角色显式授予页面和按钮 authority；
- 生产构建通过不等于真实接口、菜单、数据范围和浏览器 UAT 通过。
